▶ 被动触发时机一览›
  • turnStart — 回合开始时触发（己方回合，可加护盾/buff）
  • turnEnd — 回合结束时触发（己方回合）
  • onKill — 击杀敌人时触发（context.target 为被击杀者）
  • onKilled — 自身被击杀时触发（context.killer 为击杀者）
  • onAttack — 发起攻击时触发（context.target 为攻击目标）
  • onAttacked — 被攻击后触发（context.attacker 为攻击者，context.damage 为受到的伤害）
  • onMove — 移动结束后触发（context.from/context.to 为起止坐标）
  • onHeal — 被治疗时触发（context.healer 为治疗者，context.amount 为治疗量）
  • onSkillCast — 任意技能发动后触发（context.caster 为施法者，context.skill 为技能）
▶ 进阶：事件系统（triggerPassive / on / trigger）›

游戏有两套事件机制：被动技能触发和全局事件总线。理解它们的区别是编写复杂技能的关键。

1. Effect.triggerPassive(actor, eventName, context)

手动触发某个棋子的被动技能。会遍历该棋子身上 type === '被动' 且 trigger === eventName 的技能，依次执行 filter 判定和 content。通常由系统自动调用，但你也可以手动触发：

// 主动技能中，手动让目标触发"被攻击"被动
Effect.triggerPassive(target, "onAttacked", {
  attacker: actor,
  damage: 50
});

2. Effect.on(eventName, callback) / Effect.trigger(eventName, context)

全局事件总线（观察者模式）。on 注册回调，trigger 触发所有已注册的回调。用于系统级逻辑，而非棋子技能本身。

// 注册全局监听：任意棋子被击杀时记录
var killLog = function(ctx) {
  var victim = ctx.victim;
  Game.log(victim.name + " 倒下了！");
};
Effect.on("onKilled", killLog);

// 触发自定义事件（其他技能可监听）
Effect.trigger("myCustomEvent", { actor: actor });

// 取消监听（需保存原回调引用）
Effect.off("onKilled", killLog);

3. 两者的区别

  • triggerPassive — 调用棋子身上的被动技能，actor 就是技能拥有者
  • on/trigger — 调用全局注册的回调函数，context.actor 是事件视角（如攻击者/击杀者）

⚠️ 注意：DIY 被动技能统一走 triggerPassive。on/trigger 主要用于系统级处理（如小兵品质被动、临时技能过期），不要在 on 里直接写棋子被动逻辑，否则会因为 context 视角错误（如 onKilled 的 actor 是击杀者而非被杀者）导致误触发。

4. 各事件的 context 字段

  • onKilled — { actor(击杀者), target, victim, damage }
  • onAttack — { actor(攻击者), target, damage }
  • onAttacked — { actor(攻击者), target(被攻击者), damage }
  • onMove — { actor, from:{x,y}, to:{x,y} }
  • onHeal — { actor, amount }
  • onSkillCast — { actor(施法者), skill }
  • turnStart / turnEnd — { side, turn }

5. 实战示例：连击被动

攻击时触发自身另一个被动，实现"连击"效果：

// 技能A：onAttack 被动 — 攻击后有概率触发连击
// trigger: onAttack
if (Effect.chance(0.3)) {
  Game.log(actor.name + " 触发连击！");
  // 再次普攻同一目标
  if (target.alive) Effect.basicAttack(actor, target);
}

限定技 limited：在技能定义中设置 limited: true 即可将技能标记为限定技。限定技每局游戏只能使用一次，使用后按钮变为禁用状态并显示"已用"。

// DIY 技能定义示例
{
  id: "diy_ganning_jieying",
  name: "劫营",
  type: "主动",
  limited: true,    // 限定技：本局仅一次
  cooldown: 0,
  desc: "限定技。突袭至目标位置..."
}

临时技能 Effect.gainTmpSkill：给棋子临时添加一个技能，支持多种过期方式。

// 持续到下回合开始（回合开始时递减）
Effect.gainTmpSkill(actor, 'skillId', { turnsAtStart: 1 });

// 持续2回合（每回合结束时递减）
Effect.gainTmpSkill(actor, 'skillId', { turns: 2 });

// 使用技能后消失（触发 onSkillCast 事件时移除）
Effect.gainTmpSkill(actor, 'skillId', { expiresOn: 'onSkillCast' });

// 第5回合结束时消失
Effect.gainTmpSkill(actor, 'skillId', { expiresAtTurn: 5 });

// 手动移除
Effect.loseTmpSkill(actor, tmpId);
Effect.loseAllTmpSkills(actor);

▶ AI 提示 aiHint 详解›

aiHint 是技能的可选字段，告诉 AI 如何评估和使用此技能。

💡 自动推断模式（推荐）：留空 type 字段时，系统会通过 SkillAnalyzer 自动分析技能 content 源码，推断类型/目标/威力等语义。新技能无需手动填写即可被 AI 正确使用。只有当自动推断不准确时，才需要手动覆盖。

字段一览（所有字段均可选，留空走自动推断）：

  • type（手动覆盖时必填）— 技能类型：damage伤害 / heal治疗 / buff增益 / debuff减益 / control控制 / teleport位移 / summon召唤 / mixed混合
  • target（手动覆盖时必填）— 目标类型：enemy敌方单体 / ally友方单体 / cell格子 / self自身 / none无目标 / aoe_enemy范围敌方 / aoe_ally范围友方
  • power（0-200，默认30）— 威力值，影响基础评分。伤害类对应伤害量，治疗类对应治疗量
  • priority（1-10，默认5）— 优先级，越高越优先使用
  • condition（默认 always）— 使用条件，不满足时 AI 不会用此技能：
    • always 总是评估
    • enemy_near 附近 4 格内有敌人
    • enemy_in_range 技能范围内有敌人
    • ally_injured 有友军血量低于阈值
    • self_low_hp 自身血量低于阈值
    • self_full_hp 自身满血
    • has_target 有合法目标
  • preferTarget（默认空）— 目标偏好策略：
    • low_hp 优先低血目标（补刀）
    • high_threat 优先高威胁目标
    • injured_ally 优先残血友军（治疗）
    • nearest 优先最近敌人
    • caster 优先法师型单位（低防高攻）
  • minTargets（0-10，默认0）— 范围技至少命中 N 个目标才使用
  • avoidSelf（bool，默认 false）— 是否避免选自己作为目标
  • hpThreshold（0-100，默认0）— 血量阈值百分比，配合 self_low_hp/ally_injured 使用，0 表示用默认值（40%/70%）
  • notes（字符串）— 设计备注，不参与 AI 计算，仅作记录

评分公式：score = power * (0.5 + priority / 10)，再根据 type/condition/minTargets 调整。

示例：关羽武圣（额外攻击+回血）：

aiHint: {
  type: 'damage',
  target: 'self',        // 自身增益
  power: 50,
  priority: 5,
  condition: 'enemy_near', // 附近有敌时才用
  preferTarget: 'high_threat'
}

提示：aiHint 只影响 AI 决策，不影响技能实际效果。技能效果完全由 content 代码决定。

▶ 选项模态框 chooseOption›

Effect.chooseOption(actor, opts) 显示一个模态框让玩家选择，AI 模式下自动选择最优项。适合「分支选择」类技能（如：强攻 / 防御 / 治疗三选一）。

参数结构：

const choice = await Effect.chooseOption(actor, {
  title:    '请选择效果',        // 模态框标题
  hintText: '发动分支技能！',    // 战报提示（可选）
  options: [                    // 选项数组
    {
      label:  '强攻',           // 显示文本（必填）
      desc:   '+30 攻击力',     // 描述（可选）
      value:  'atk',            // 选项值（可选）
      aiScore: 60,              // AI 评分（默认 0，越高越优）
      aiCondition: function(actor) {  // AI 可用条件（可选）
        return true;
      }
    },
    {
      label:  '治疗',
      desc:   '回复 50 生命',
      value:  'heal',
      aiScore: 80,
      aiCondition: function(actor) {
        return actor.hp < actor.maxHp * 0.5;  // 仅低血时 AI 会选
      }
    }
  ],
  aiPicker: null  // 自定义 AI 选择函数 (actor, options) => option（可选）
});

if (choice) {
  // choice = { label, desc, value, aiScore, _index }
  if (choice.value === 'atk') {
    Effect.modifyAttack(actor, 30, 2);
  } else if (choice.value === 'heal') {
    Effect.heal(actor, 50);
  }
  Game.log(actor.name + ' 选择了 ' + choice.label);
}

AI 选择逻辑（自动执行）：

  1. 若提供 aiPicker 函数，优先调用它
  2. 否则过滤掉 aiCondition 返回 false 的选项
  3. 按 aiScore 排序，最高分当选（同分随机）
  4. 全部不可用则返回 null（AI 放弃此技能）

返回值：选中选项对象（含 label/desc/value/aiScore 等 + _index）或 null（玩家取消 / AI 无可用项）。

提示：必须用 await 等待玩家选择。AI 模式下会立即返回不阻塞。

▶ 多步技能与 AI 支持›

多步技能指 content 代码中包含一个或多个 await Effect.chooseXxx() 的技能，例如「先选格子 → 再对范围内敌人造成伤害」或「让玩家从 3 个效果中选 1 个」。

AI 自动支持：AI 执行技能时，会设置 Effect._aiContext 并贯穿整个 content 的 async 执行。content 内部的 chooseCell/chooseEnemy/chooseAlly/chooseOption 检测到 AI 模式后会立即返回 AI 选择的结果（不弹窗、不阻塞），让多步流程顺畅跑完。

AI 选择依据：

  • chooseCell/chooseEnemy/chooseAlly：根据 aiHint.target / preferTarget / avoidSelf 自动选最优格子或棋子
  • chooseOption：根据 aiScore / aiCondition / aiPicker 自动选最优选项

content 返回 false 的约定：

如果 AI（或玩家）在中间步骤取消选择（chooseXxx 返回 null），content 应该 return false。AI 引擎检测到 result === false 时不会应用冷却，并继续评估其他行动。

// 多步技能示例：先选格子，再对范围内敌人造成伤害
async function content(actor) {
  const cell = await Effect.chooseCell(actor, {
    range: { shape: '+', n: 3 },
    mustEmpty: false,    // 可以选到敌人
    hintText: '请选择目标格'
  });
  if (!cell) return false;  // 取消则不消耗技能

  const cells = Range.cellsInRange('r', 1, cell.x, cell.y, { includeSelf: true });
  let hit = 0;
  for (const c of cells) {
    const t = Game.pieceAt(c.x, c.y);
    if (t && t.alive && t.side !== actor.side) {
      Effect.damage(actor, t, 50);
      hit++;
    }
  }
  if (hit === 0) return false;  // 没命中任何敌人也算未使用

  actor.skilled = true;
  return true;
}

自定义 AI 逻辑：在 content 内可调用 Effect.aiContext() 检测当前是否 AI 模式，并写分支逻辑：

async function content(actor) {
  let target;
  const aiCtx = Effect.aiContext();
  if (aiCtx) {
    // AI 模式：自定义选目标逻辑
    target = Game.pieces.filter(p => p.alive && p.side !== actor.side)
      .sort((a, b) => a.hp - b.hp)[0];  // 选血量最低的敌人
  } else {
    // 玩家模式：弹窗选择
    target = await Effect.chooseEnemy(actor, { range: { shape: '+', n: 5 } });
  }
  if (!target) return false;
  Effect.damage(actor, target, 80);
  actor.skilled = true;
}

提示：尽量用 chooseXxx 让 AI 自动决策；只有需要复杂自定义逻辑时才用 aiContext() 分支。

▶ ★ 新效果 API 详解›

以下为新增的高性价比 Effect，每个附带完整示例：

1. 不屈 Effect.undying(target, stacks)

致命伤害时保留 1 点生命，消耗一层标记。stacks 可叠加（挡多次致命伤）。

// 主动技能：给己方核心武将2层不屈
const ally = await Effect.chooseAlly(actor, {
  range: { shape: 'r', n: 2 },
  hintText: '请选择友方'
});
if (!ally) return false;
actor.skilled = true;
Effect.undying(ally, 2);
return true;

2. 复活 Effect.revive(target, turns, ratio)

死亡后延迟 turns 回合，以 ratio 比例血量复活。位置被占时自动找最近空位。

// 被动技能（turnStart）：每回合开始给自己复活标记
// trigger: turnStart
Effect.revive(actor, 3, 0.3); // 死后3回合以30%血量复活
Game.log(actor.name + ' 祭起复活术！');

3. 隐身 Effect.stealth(target, turns)

隐身期间无法被选为攻击/技能目标（AI 和玩家都无法选中）。棋子半透明显示。

// 主动技能：自身隐身2回合
actor.skilled = true;
Effect.stealth(actor, 2);
return true;

配合 Effect.isUntargetable(piece) 可在代码中检查某棋子是否隐身：

if (Effect.isUntargetable(target)) {
  Game.log(target.name + ' 处于隐身，无法选中！');
  return false;
}

4. 标记引爆 Effect.detonate(target, markName, callback)

消耗目标身上的指定标记，执行回调函数 callback(piece, markData)，然后移除标记。让"叠加标记→引爆"的 Combo 流成为可能。

// 主动技能：先叠加3层"破绽"标记，再引爆
const target = await Effect.chooseEnemy(actor, {
  range: { shape: '+', n: 3 }
});
if (!target) return false;
actor.skilled = true;

// 检查是否有"破绽"标记
var data = Effect.getMarkData(target, 'flaw');
if (data && data.stacks >= 3) {
  // 引爆：每层造成20点真实伤害
  Effect.detonate(target, 'flaw', function(piece, d) {
    Effect.damage(actor, piece, d.stacks * 20, { ignoreDef: true });
  });
  Game.log('【破绽引爆】造成 ' + (data.stacks * 20) + ' 真实伤害！');
} else {
  // 叠加标记
  var cur = data ? data.stacks : 0;
  Effect.unmark(target, 'flaw');
  Effect.mark(target, 'flaw', {
    display: '破',
    modifiers: { flawStacks: cur + 1 },
    data: { stacks: cur + 1 }
  });
  Game.log(target.name + ' 身上破绽+1（当前 ' + (cur + 1) + ' 层）');
}
return true;

5. 属性偷取 Effect.stealStat(actor, target, stat, amount)

永久从 target 偷取 amount 点属性给 actor。stat 为 'atk' 或 'def'。不会恢复！

// 被动技能（onAttack）：攻击时偷取5点攻击力
// trigger: onAttack
if (!context || !context.target) return;
var t = context.target;
if (t.alive) {
  Effect.stealStat(actor, t, 'atk', 5);
}

6. 陷阱 Effect.placeTrap(x, y, opts)

在指定格子放置陷阱，敌方棋子踩到时自动触发。opts.type 支持：damage(伤害) / stun(眩晕) / teleport(随机传送) / poison(中毒)。

// 主动技能：在目标格布雷
const cell = await Effect.chooseCell(actor, {
  range: { shape: '+', n: 3 },
  mustEmpty: true,
  hintText: '请选择布雷位置'
});
if (!cell) return false;
actor.skilled = true;
Effect.placeTrap(cell.x, cell.y, {
  type: 'damage',   // 类型：damage/stun/teleport/poison
  damage: 40,       // 伤害量（damage/poison类型用）
  turns: 3,         // 3回合后自动消失
  owner: actor,     // 陷阱归属
  side: 'enemy'     // 敌方触发
});
return true;

清除陷阱：Effect.clearTraps({owner: actor}) 或 Effect.clearTraps({x, y}) 或 Effect.clearTraps()（清全部）。

7. 伤害分摊 Effect.linkDamage(allyA, allyB, turns, ratio)

链接两个友军，任一方受伤时转移 ratio 比例伤害给另一方。分摊伤害会正确触发不屈/护盾/死亡事件。

// 主动技能：链接自己和一名友军，分摊50%伤害
const ally = await Effect.chooseAlly(actor, {
  range: { shape: 'r', n: 3 },
  hintText: '请选择链接友军'
});
if (!ally) return false;
actor.skilled = true;
Effect.linkDamage(actor, ally, 3, 0.5); // 3回合内分摊50%
return true;

▶ ★ API 参数详解（选择类）›

所有 choose 系列方法均为 async，必须用 await 等待返回值。

Effect.chooseEnemy(actor, opts) — 选择敌人

让玩家点选范围内的敌方棋子，返回棋子对象或 null。AI 模式自动选最优目标。

  • actor（Piece，必填）— 施法者棋子，用于确定范围中心
  • opts.range（{shape, n}，默认 {shape:'square', n:3}）— 可选范围形状
  • opts.center（{x,y}，可选）— 自定义中心点，默认为 actor 位置
  • opts.passThrough（bool，默认 false）— true 时范围不被棋子阻挡（穿透墙壁/棋子计算距离）
  • opts.mustEnemy（bool，内部自动设为 true）— 强制只能选敌方
  • opts.hint（字符串，可选）— 高亮格子样式标记
  • opts.hintText（字符串，可选）— 显示在战报中的提示文本
  • opts.filter（function(cell, piece)=>bool，可选）— 自定义过滤函数，返回 false 的格子不可选
  • opts.ignoreStealth（bool，默认 false）— true 时可选中隐身单位
const target = await Effect.chooseEnemy(actor, {
  range: { shape: '+', n: 3 },
  passThrough: true,
  filter: function(cell, piece) { return piece.hp > 50; },
  hintText: '请选择敌人'
});

Effect.chooseAlly(actor, opts) — 选择友方

参数与 chooseEnemy 完全一致，但自动限定为友方棋子（mustAlly: true）。

const ally = await Effect.chooseAlly(actor, {
  range: { shape: 'r', n: 2 },
  filter: function(cell, piece) { return piece.hp < piece.maxHp; }
});

Effect.chooseCell(actor, opts) — 选择格子

让玩家点选一个格子，返回 {x, y} 或 null。chooseEnemy/chooseAlly 底层都调用此方法。

  • actor（Piece，必填）— 施法者棋子
  • opts.range（{shape, n}，默认 {shape:'square', n:3}）— 可选范围
  • opts.center（{x,y}，可选）— 自定义中心点
  • opts.passThrough（bool，默认 false）— 范围是否穿透障碍
  • opts.mustEmpty（bool，默认 false）— true 时空格才能选
  • opts.mustEnemy（bool，可选）— true 时只有有敌方棋子的格可选
  • opts.mustAlly（bool，可选）— true 时只有有友方棋子的格可选
  • opts.mustSelf（bool，可选）— true 时只能选 actor 自身所在格
  • opts.filter（function(cell, piece)=>bool，可选）— 自定义过滤
  • opts.ignoreStealth（bool，默认 false）— 可选隐身单位
  • opts.hint（字符串，可选）— 高亮样式标记
  • opts.hintText（字符串，可选）— 战报提示文本
const cell = await Effect.chooseCell(actor, {
  range: { shape: '+', n: 3 },
  mustEmpty: true,
  filter: function(cell, piece) { return cell.x >= 3; }
});

Effect.chooseOption(actor, opts) — 选项模态框

显示模态框让玩家从选项中选择，AI 自动选最优项。返回选中项对象或 null。

  • actor（Piece，必填）— 施法者棋子
  • opts.title（字符串，可选）— 模态框标题
  • opts.hintText（字符串，可选）— 战报提示文本
  • opts.options（数组，必填）— 选项列表，每项为对象：
    • label（字符串，必填）— 显示文本
    • desc（字符串，可选）— 描述文字
    • value（任意，可选）— 选项值
    • aiScore（数字，默认0）— AI 评分，越高越优先
    • aiCondition（function(actor)=>bool，可选）— AI 可用条件
  • opts.filter（function(option)=>bool，可选）— 过滤选项，返回 false 的选项不显示
  • opts.aiPicker（function(actor, options)=>option，可选）— 自定义 AI 选择函数
const choice = await Effect.chooseOption(actor, {
  title: '请选择效果',
  options: [
    { label: '强攻', desc: '+30攻击', value: 'atk', aiScore: 60 },
    { label: '治疗', desc: '回复50HP', value: 'heal', aiScore: 80,
      aiCondition: function(a) { return a.hp < a.maxHp * 0.5; } }
  ],
  filter: function(opt) { return opt.value !== 'heal' || actor.hp < actor.maxHp; }
});
▶ ★ API 参数详解（战斗类）›

Effect.damage(actor, target, amount, opts) — 造成伤害

  • actor（Piece|null）— 伤害来源，null 表示无来源（陷阱等）
  • target（Piece，必填）— 受害目标
  • amount（number，必填）— 基础伤害值
  • opts.mul（number，默认1）— 伤害倍率，最终伤害 = max(1, floor(atk * mul))
  • opts.ignoreDef（bool，默认false）— true 时无视防御力（真实伤害）
  • opts.ignoreShield（bool，默认false）— true 时无视护盾
  • opts._isShared（bool，内部使用）— 标记为分摊伤害，避免递归
// 1.5倍伤害，无视防御
Effect.damage(actor, target, 80, { mul: 1.5, ignoreDef: true });
// 普通伤害
Effect.damage(actor, target, Effect.getEffectiveAttack(actor));

Effect.heal(actor, amount) — 治疗

  • actor（Piece，必填）— 治疗目标
  • amount（number，必填）— 治疗量，不会超过 maxHp
Effect.heal(actor, 50); // 回复50HP

Effect.chain(actor, target, amount, count, opts) — 链式弹射

对 target 造成伤害后，自动弹射到最近的 count 个敌方目标，每次衰减。

  • actor（Piece，必填）— 施法者
  • target（Piece，必填）— 首个目标
  • amount（number，必填）— 首次伤害量
  • count（number，默认2）— 弹射次数（不含首个目标）
  • opts.decay（number，默认0.6）— 每次弹射伤害衰减比例
  • opts.mul / opts.ignoreDef / opts.ignoreShield — 同 damage
Effect.chain(actor, target, 100, 3, { decay: 0.5, ignoreDef: true });
// 100 → 50 → 25 → 12 伤害链式弹射4个目标

Effect.modifyAttack(target, delta, turns) — 攻击力增减

  • target（Piece，必填）— 目标棋子
  • delta（number，必填）— 增减值，正数增益，负数减益
  • turns（number，默认1）— 持续回合数
Effect.modifyAttack(actor, 30, 2); // 攻击力+30，持续2回合
Effect.modifyAttack(target, -20, 3); // 攻击力-20，持续3回合

Effect.modifyDef(target, delta, turns) — 防御力增减

参数同 modifyAttack，作用于防御力。

Effect.modifyAttackRange(target, delta, turns) — 攻击范围增减

参数同 modifyAttack，delta 为攻击范围格数的增减值。

Effect.shield(target, amount) — 添加护盾

  • target（Piece，必填）— 目标棋子
  • amount（number，必填）— 护盾值，受到伤害时优先扣除
Effect.shield(actor, 50); // 获得50点护盾

Effect.getEffectiveAttack(actor) — 获取有效攻击力

返回基础攻击力 + 所有增益标记的总和。用于 damage 的 amount 参数。

Effect.getEffectiveDefense(target) — 获取有效防御力

返回基础防御力 + 所有增益标记的总和。

Effect.getEffectiveAttackRange(actor) — 获取有效攻击范围 ★

返回 {shape, n}，含 modifyAttackRange 的加成。用于判断能打到哪些格子。

var atkRange = Effect.getEffectiveAttackRange(actor);
var cells = Range.cellsInRange(atkRange.shape, atkRange.n, actor.x, actor.y);

Effect.getEffectiveMoveRange(actor) — 获取有效移动范围 ★

返回 {shape, n}，含 modifyMoveRange 的加成。

Effect.mark(target, name, opts) — 添加标记（通用）

所有状态效果（眩晕/中毒/护盾等）底层都基于 mark 实现。可自定义任意标记。

  • target（Piece，必填）— 目标棋子

Effect.pull(actor, target, n) — 拉拽

将目标向 actor 方向拉 n 格。参数同 push（无 dir，自动朝 actor 方向）。

Effect.summonUnit(actor, x, y, opts) — 召唤单位

  • actor（Piece，必填）— 召唤者
  • x, y（number，必填）— 召唤坐标，必须为空
  • opts.id（字符串，可选）— 单位 ID 前缀
  • opts.name（字符串，可选）— 显示名称
  • opts.hp（number，默认60）— 生命值
  • opts.atk（number，默认0）— 攻击力
  • opts.def（number，默认0）— 防御力
  • opts.moveRange（{shape,n}，默认{shape:'+',n:0}）— 移动范围
  • opts.attackRange（{shape,n}，默认{shape:'+',n:0}）— 攻击范围
  • opts.moved / opts.attacked / opts.skilled（bool，默认true）— 召唤当回合是否已行动
  • opts.templateId（字符串，可选）— 使用已有武将/小兵模板的 ID
  • opts.portrait（字符串，可选）— 立绘文件名
  • opts.skills（数组，可选）— 技能列表，每项为字符串ID或技能对象
const unit = Effect.summonUnit(actor, 3, 4, {
  name: '影分身', hp: 80, atk: 30, def: 10,
  moveRange: { shape: '+', n: 2 },
  attackRange: { shape: '+', n: 1 }
});

Effect.placeTrap(x, y, opts) — 放置陷阱

  • x, y（number，必填）— 陷阱坐标
  • opts.type（字符串，默认'damage'）— 陷阱类型：damage伤害 / stun眩晕 / teleport随机传送 / poison中毒
  • opts.damage（number，默认30）— 伤害/中毒量
  • opts.turns（number，默认3）— 几回合后自动消失
  • opts.owner（Piece，可选）— 陷阱归属者
  • opts.side（字符串，默认'enemy'）— 触发阵营：enemy敌方触发 / ally友方触发
  • opts.data（对象，可选）— 自定义数据（如 stun 的 turns、teleport 的 range）

Effect.clearTraps(opts) — 清除陷阱

  • opts.x, opts.y — 清除指定坐标的陷阱
  • opts.owner — 清除指定归属者的陷阱
  • 不传参数 — 清除全部陷阱

Effect.linkDamage(allyA, allyB, turns, ratio) — 伤害分摊

  • allyA, allyB（Piece，必填）— 两个友军
  • turns（number，默认2）— 持续回合

▶ ★ API 参数详解（搜索/工具类）›

Effect.searchPiece(range, filter, opts) — 搜索棋子

返回符合条件的棋子数组。filter 支持丰富的过滤条件。

  • range（{shape, n, center:{x,y}} 或 null）— 搜索范围，null 表示全棋盘
  • filter（对象）— 过滤条件：
    • side（字符串）— 'enemy'敌方 / 'ally'友方 / 具体阵营名
    • alive（bool）— true 仅存活 / false 仅死亡
    • type（字符串）— '武将' / '小兵'
    • hp（[min, max]）— 当前血量区间
    • maxHp / atk / def（[min, max]）— 属性区间
    • name（字符串）— 名称包含匹配
    • minionId / generalId / rarity（字符串）— 精确匹配
    • custom（function(piece)=>bool）— 自定义过滤函数
  • opts.actor（Piece，可选）— 用于判断 side 的参考者
  • opts.includeSelf（bool，默认true）— 是否包含 actor 自身
// 搜索血量低于50%的敌方武将
var weak = Effect.searchPiece(null, {
  side: 'enemy',
  type: '武将',
  hp: [0, 100],
  custom: function(p) { return p.hp < p.maxHp * 0.5; }
}, { actor: actor });

Effect.searchCell(range, filter) — 搜索格子

返回符合条件的格子数组 [{x, y, piece}]。

  • range（{shape, n, center:{x,y}} 或 null）— 搜索范围
  • filter（对象）— 过滤条件：
    • empty（bool）— true 仅空格
    • occupied（bool）— true 仅被占据
    • ownHalf（'red'|'blue'）— 仅指定方半场
    • terrain（字符串）— 仅指定地形：r/m/f/w/plain
    • piece（filterObj）— 格上棋子需满足 searchPiece 过滤
    • custom（function(cell, piece)=>bool）— 自定义过滤
// 搜索 actor 附近3格内的空格
var cells = Effect.searchCell(
  { shape: 'r', n: 3, center: { x: actor.x, y: actor.y } },
  { empty: true }
);

▶ ★ API 参数详解（视觉特效 Effect.fx）›

所有特效均为即时播放、自动清理，不影响游戏逻辑。

Effect.fx.highlightCells(cells, opts) — 高亮格子 ★

在指定格子上叠加半透明色块，持续到自动过期或被 clearFx 清除。

  • cells（数组|对象，必填）— 高亮目标：
    • 数组：[{x,y}, {x,y}, ...] — 精确指定格子
    • 对象：{shape, n, cx, cy} — 范围定义，自动计算格子
  • opts.color（字符串，默认'rgba(255,180,0,0.35)'）— CSS 颜色值
  • opts.duration（number，默认0）— 持续毫秒数，0 = 持续到手动清除
  • opts.dashed（bool，默认false）— true 时显示虚线边框而非色块
  • opts.id（字符串，可选）— 自定义标识，用于后续 clearFx 精确清除
// 高亮圆形2格范围，3秒后自动消失
var fxId = Effect.fx.highlightCells(
  { shape: 'r', n: 2, cx: actor.x, cy: actor.y },
  { color: 'rgba(255,180,0,0.35)', duration: 3000, id: 'myZone' }
);
// 持续显示，稍后手动清除
Effect.fx.clearFx('myZone');

Effect.fx.clearFx(id) — 清除高亮 ★
